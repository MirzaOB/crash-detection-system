# Mobile Crash Detection System

A web application that uses a mobile device's accelerometer to detect potential crash events. The system monitors real-time motion data and alerts when significant impacts are detected.

## Features

- Real-time accelerometer data monitoring
- Visual status indicators based on motion intensity
- Live acceleration graph with historical data
- Crash detection with countdown timer
- Dark/light mode toggle
- Emergency alert system with countdown

## Technology Stack

- Frontend: HTML, JavaScript, Tailwind CSS
- Backend: Flask (Python)
- Data Visualization: Chart.js
- Sensor Access: DeviceMotion API

## How to Use

1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py` or `./start.sh`
4. Access the web app on your mobile device at the provided URL
5. Click "Start Detection" to begin monitoring

## Requirements

- Python 3.6+
- Flask 3.0.3
- Mobile device with accelerometer and modern browser
